Neon Coast is an offline web app that turns your photos and a caption into GTA-style multi-panel cover art. Pick one of four layouts (2×2 grid, hero + strip, 3 vertical panels, or a single hero), fill each panel with your own photo or a sample, drag to crop and zoom, write the caption, pick a Sunset, Neon or Gold grade, and export a PNG at 1080×1080, 1080×1350 or 1920×1080. Everything runs in your browser from static files — no upload, no network, no Rockstar logo, artwork or font. The preview and the export are the same drawing, painted at full size on an offscreen canvas.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

To hand the entry in, run:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
